# 基于 LVGL 的网络可控贪吃蛇

一个跑在 **ARM Linux 开发板**上的贪吃蛇项目。用 LVGL 直接驱动帧缓冲绘制界面，除了本地触摸屏操作，还能通过 **TCP 网络**用手机 / PC 远程控制方向、暂停和重来。

它不只是一个小游戏，更是一条完整的嵌入式 Linux 应用开发链路：帧缓冲显示、evdev 触摸输入、LVGL 图形渲染、Socket 网络通信、POSIX 多线程与线程安全，最后交叉编译并部署到开发板。

## 功能特性

- **LVGL 图形界面**：直接驱动 `/dev/fb0` 帧缓冲，蛇身、食物、方向键、计分板全部用 LVGL 绘制；
- **本地触控操作**：点击游戏区域按蛇头相对位置转向，或点击右侧方向按钮；
- **TCP 远程控制**：独立线程运行 TCP 服务端，手机 / PC 作为客户端发送单字符指令即可远程操作；
- **暂停 / 继续 / 一键重来**：本地按钮和网络指令都能触发；
- **完整游戏逻辑**：300ms 定时步进、方向防掉头、边界与自撞检测、吃食物加分变长；
- **断线自动恢复**：客户端断开后服务端自动回收连接，重新回到监听状态等待下一个客户端；
- **线程安全**：互斥锁保护共享状态，网络线程不直接操作 LVGL，界面更新统一在主线程执行。

## 系统架构

系统按四层划分，数据从下往上、控制从上往下：

```
┌──────────────────────────────────────────────┐
│  业务层  游戏玩法逻辑 / TCP 网络控制服务        │
├──────────────────────────────────────────────┤
│  图形层  LVGL：UI 渲染、事件分发、定时器        │
├──────────────────────────────────────────────┤
│  系统层  Linux 内核：Frame Buffer / Input 子系统│
├──────────────────────────────────────────────┤
│  硬件层  ARM 开发板 + LCD 触摸屏               │
└──────────────────────────────────────────────┘
```

线程模型与数据流：

```
  网络线程 (network_thread_func)                 主线程 (main)
  ──────────────────────────────                 ───────────
  socket / bind / listen / accept
  recv 单字符指令
        │  方向指令：加锁 -> 写 next_dir
        │  暂停指令：加锁 -> net_pause_toggle = true
        │  重置指令：        net_reset_request = true
        └──────────────► 主循环检测标志位
                            lv_timer_handler()
                            消费标志 -> 操作 LVGL 更新界面
```

关键点：**LVGL 不是线程安全的**，所以网络线程绝不调用 LVGL API，只改数据或置标志位；所有界面操作都回到主线程、在 `lv_timer_handler()` 的上下文中执行。

## 快速开始

### 1. 获取代码（含 LVGL 子模块）

```bash
git clone --recurse-submodules https://github.com/LL-yanyan/lvgl-snake.git
cd lvgl-snake
```

如果克隆时忘了加 `--recurse-submodules`，可以补拉：

```bash
git submodule update --init --recursive
```

### 2. 准备界面图标资源

游戏按钮使用 BMP 图标，运行时从**可执行文件所在工作目录**加载。请在开发板上把以下图标放到程序同目录：

| 文件名 | 用途 |
| --- | --- |
| `up.bmp` | 向上方向键 |
| `down.bmp` | 向下方向键 |
| `left.bmp` | 向左方向键 |
| `right.bmp` | 向右方向键 |
| `pause.bmp` | 暂停按钮 |
| `continue.bmp` | 暂停后显示的“继续”按钮 |
| `reset.bmp` | 重来按钮 |

> 这些图标属于运行时资源，不含在本仓库中；也可以自行替换 `snake_server.c` 中的图片路径。

### 3. 交叉编译（在虚拟机 / Linux 主机上）

先按实际安装路径编辑 `aarch64-linux-gnu.toolchain.cmake` 中的编译器路径，然后：

```bash
cmake -B build -DCMAKE_TOOLCHAIN_FILE=aarch64-linux-gnu.toolchain.cmake
cmake --build build -j
```

生成的可执行文件为 `build/src/lvgl_snake`。

### 4. 部署到开发板并运行

```bash
# 通过 scp / nfs / u 盘等方式把可执行文件和图标一起拷到开发板
scp build/src/lvgl_snake root@<开发板IP>:/root/

# 在开发板上运行（访问帧缓冲可能需要 root）
cd /root
./lvgl_snake
```

启动成功后，串口 / 终端会打印：

```
[网络] 控制服务已启动，监听 192.168.118.148:10086
```

## 网络控制协议

协议刻意做得非常简单：客户端建立 TCP 连接后，每发送 **1 个字符**就是一条指令，大小写均可：

| 指令（大小写均可） | 功能 |
| --- | --- |
| `U` / `u` | 向上 |
| `D` / `d` | 向下 |
| `L` / `l` | 向左 |
| `R` / `r` | 向右 |
| `P` / `p` | 暂停 / 继续 切换 |
| `Z` / `z` | 重置游戏 |

示例（Linux 下用 nc 测试）：

```bash
# 连接后手动敲入 U D L R P Z 等字符并回车
nc 192.168.118.148 10086
```

手机端可以使用任意“TCP 调试 / 网络调试助手”类 App，作为客户端连上开发板 IP 和端口后发送上述字符。

方向指令带有**防掉头**判断（例如正在向右走时直接发“向左”会被忽略）；游戏结束或暂停状态下也会拒绝改向。

## 多线程安全设计

这是本项目最核心的设计点：

1. **互斥锁 `game_mutex`**：所有共享状态（方向、暂停 / 结束标志、分数等）的读写都在加锁后的临界区中进行，保证访问串行化；
2. **网络线程只改数据 / 置标志位**：网络线程可以在锁保护下修改 `next_dir`，但对于“暂停”“重置”这类必须操作 UI 的请求，只设置 `net_pause_toggle`、`net_reset_request` 标志；
3. **主线程统一更新 UI**：主循环在 `lv_timer_handler()` 附近检测标志位，在 LVGL 所在的同一线程完成暂停切换、定时器暂停 / 恢复和界面重绘。

这样既避免了多线程调用 LVGL 导致的花屏、崩溃，也保证网络 IO 不会阻塞图形渲染。

## 自定义配置

- **开发板 IP / 端口**：修改 `src/snake_server.c` 顶部的 `NET_IP`、`NET_PORT` 宏；
- **显示 / 输入设备节点**：修改 `src/main.c` 中的 `/dev/fb0`、`/dev/input/event6`；
- **网格大小 / 移动速度**：修改 `src/snake_server.c` 中的 `GRID_SIZE`、`MOVE_INTERVAL`；
- **LVGL 功能裁剪、显示分辨率**：修改根目录 `lv_conf.h`。
